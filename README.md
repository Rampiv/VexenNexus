# 🌀 Vexen Hub

**Vexen Hub** — интерактивный веб-сайт, посвящённый вселенной *Wuthering Waves*, с фокусом на резонаторах, баннерах и другом игровом контенте. Проект создан с использованием современного фронтенд-стека и оптимизирован под быструю загрузку и плавную навигацию.

> 🌐 **Демо**: [https://ww-hub.vercel.app/](https://ww-hub.vercel.app/)

---

## 🛠 Технологии

- **Фреймворк**: React 18 (с TypeScript)
- **Маршрутизация**: React Router v7 (`HashRouter` для совместимости с GitHub Pages)
- **Сборка**: Vite
- **Стили**: SCSS через `sass-embedded`
- **Тестирование**: Vitest + JSDOM
- **Развертывание**: GitHub Pages (`gh-pages`)
- **Качество кода**: ESLint + Prettier + строгая типизация TypeScript
